# EnemySense 2.0

Modernized Valheim 1.0-compatible rebuild of KodaichiZero's EnemySense/CreatureSense concept.

Preserved behavior:
- Crouch + Walk triggers sonar by default.
- Configurable stamina cost.
- Sneak skill increases detection range.
- Nearby non-player creatures get their health bars revealed.
- Optional minimap pins, message, visual effect, audio effect, and extra minimap zoom.
- Optional dedicated KeyboardShortcut keybind.
